# AVERIQ — Financial work, prepared

A responsive, single-page website concept for the AVERIQ internship assignment. Built with React, TypeScript, Vite, Tailwind CSS, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local URL in the terminal (usually `http://localhost:5173`). To create a production build:

```bash
npm run build
npm run preview
```

## Page structure

- Hero and review-workspace illustration
- End-to-end solutions
- Standalone tools
- Interactive technology-capability walkthrough
- Document-to-decision workflow
- Software preparation vs. professional review
- About AVERIQ
- Interactive FAQ, demo request preview and footer

## Content and product accuracy

Product names, audiences, capabilities, company background, brand direction, and the human-review principle are based on the supplied assignment brief. The brief says some offerings are already in use and others are in development; the page avoids presenting all offerings as universally available. Alkazim's public site informs industry context and professional tone only. Alkazim's tax, bookkeeping, advisory, consultancy, risk, and business-setup services are not presented as AVERIQ software products.

The hero workspace and capability walkthrough are illustrative samples, not screenshots of a live AVERIQ product or customer data. Their changing counters and states are a visual prototype. No customer names, testimonials, adoption numbers, or performance figures are invented.

The visual structure takes cues from the Northline Studio reference: an atmospheric full-screen hero, technical line-work diagrams, editorial workflow panels, restrained instrument-style UI, and a clear closing CTA. Northline content, project claims, team names, and credentials are not used. AVERIQ product categories and copy remain grounded in its own assignment. The dark graphite and acid-lime visual system is adapted for AVERIQ while keeping the supplied mark unchanged.

Motion is adapted from the Northline reference for AVERIQ content: the hero uses the supplied glow image, the header contracts into a floating glass bar, the headline reveals in sequence, workflow diagrams animate their signal paths, two product/workflow marquees loop, the review workspace updates as an illustrative simulation, content reveals on scroll, and the local demo preview shows a short processing state. Reduced-motion preferences disable continuous effects.

The demo form is a local interaction only. It does not send, store, or persist submitted details. Connect an approved contact destination before publishing or submitting a live URL.
