# AVERIQ — Financial Work, Prepared

A sleek, responsive landing page for **AVERIQ**, built to show how modern software and financial professionals work together — software prepares the work, professionals make the decisions.

Built with React, TypeScript, Tailwind CSS, and Vite.

---

## ✨ Highlights

- **Responsive & polished**: Looks sharp and runs smoothly across desktop, tablet, and mobile screens.
- **Interactive workflow walkthrough**: Demonstrates document extraction, cross-checking, and drafting before human sign-off.
- **Fluid micro-interactions**: Subtle glow effects, smooth scroll reveals, and responsive magnetic buttons.
- **Blazing fast**: Minimal footprint, bundled with Vite for near-instant loads.

---

## 🚀 Getting Started

### 1. Clone & install dependencies
```bash
git clone https://github.com/Satyamaxxing/AveriQ.git
cd AveriQ
npm install
```

### 2. Start the dev server
```bash
npm run dev
```
Then visit `http://localhost:5173` in your browser.

### 3. Build for production
```bash
npm run build
npm run preview
```
